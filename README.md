# Sprintly

Sprintly is a simple todo application created as part of [The Odin Project's](https://www.theodinproject.com) Full Stack JavaScript course. It helps users efficiently manage their projects and tasks.

## Features

### **Task Management**

- Create, Read, Update, and Delete tasks.
- Open a modal for a single task to view, edit, or delete its details.

### **Project Management**

- Create, Read, Update, and Delete projects.
- View all tasks within a project.

### **User Preferences**

- Dark/Light mode for a customizable user experience.

### **Performance & Rendering**

- Dynamic rendering ensures a smooth user interface without unnecessary page reloads.## 🛠️ Built With
- **HTML**
- **CSS**
- **JavaScript(ES6+)**
- **Webpack**: For bundling and optimizing project assets.

## How to Run

In order to setup and work on this project on your own, you will need to:

### **1. Clone this project**

`git clone git@github.com:lawrence-ruscia/todo-list.git`

### **2. Development Mode**

Run the application in development mode with live reloading:

```bash
npm run dev
```

### **3. Build for Production**

Create an optimized production build:

```bash
npm run build
```

### **4. Deploy to Github Pages**

Deploy the production build to GitHub Pages:

```bash
npm run deploy
```
